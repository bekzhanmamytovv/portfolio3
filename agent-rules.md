# Архитектурные паттерны и правила (Адаптация ECC для Next.js)

## 1. Sub-agent: Planner (Планировщик)
- **Роль:** Сбор требований и декомпозиция.
- **Паттерн:** Перед написанием кода всегда определять: 1) Целевую аудиторию компонента, 2) Необходимые пропсы (Data Models), 3) Краевые случаи (пустые данные, ошибки).
- **Выход:** Четкий интерфейс компонента (TypeScript Interfaces).

## 2. Sub-agent: Architect (Архитектор)
- **Роль:** Проектирование структуры и изоляция логики.
- **Паттерн:** "Smart Container / Dumb Presentation". Данные должны инжектироваться сверху (из `lib/data.ts`).
- **Стек:** Использование SSR/RSC где возможно, и `"use client"` только для интерактивных 'листьев' (кнопки, аккордеоны, модалки).

## 3. Sub-agent: Frontend (Скиллы верстки)
- **Роль:** Pixel-perfect реализация и микро-интеракции.
- **Паттерн:** "Editorial Aesthetic". Использование дизайн-токенов Tailwind (`text-[#2d2a26]`, `bg-[#faf8f5]`).
- **Анимации:** Использование `framer-motion` (или `motion/react`) для staggered-анимаций (fade-up, scale tap). Обязательное управление Safe-Area на iOS.
- **Звук:** Использование `lib/sound.ts` для тактильного отклика.

## 4. Sub-agent: Reviewer (Ревьюер)
- **Роль:** Строгий контроль качества, a11y и перформанса.
- **Паттерн:** 
  - Проверка семантики (использование `<section>`, `<article>`, `<h3>`).
  - Проверка доступности (focus rings, `aria-expanded`, keyboard navigation).
  - Проверка оптимизации (`loading="lazy"` для картинок, отсутствие лишних ререндеров).
